Image analysis pipeline for Alzheimer's drug research

Measuring how brain immune cells clear Alzheimer's protein

Researchers are testing whether a potential Alzheimer's drug helps the brain's immune cells clear a harmful protein. This pipeline measures hundreds of microscope images automatically and the same way every time, so the answer is fast, reliable and repeatable.

See how it works Request code access

The problem

Hundreds of images per experiment, and every one has to be measured the same way.

Why it matters

The science in three pictures.

  1. The protein builds up

    In Alzheimer's, amyloid-beta (green) forms clumps around the brain's immune cells (red).

  2. Immune cells take it in

    The cell swallows clumps A and B. The same green clumps now sit inside the red cell.

  3. A drug could boost this

    Same four clumps. With the drug, more of them end up inside the cell.

The pipeline measures exactly this: how much of each immune cell's area holds the protein, across every image.
